# Diet Rep — Nutrition & Training Log

This repository tracks meals, estimated calories/macros, body-weight trends, and training context to support gradual fat loss while maintaining running, cycling, and strength performance.

## How to use
- Add each meal to `FOOD_LOG.md` with a photo description, portion assumptions, and an estimated calorie/protein/carbohydrate/fat range.
- Mark estimates as approximate; cafeteria cooking oil, sauces, and portion sizes can create substantial uncertainty.
- Record daily weight under consistent conditions and use weekly averages rather than reacting to one weigh-in.
- Keep training fuel and recovery in mind. Avoid aggressive calorie restriction on hard training days.
